# Ant1Van Homebrew Tap

Official Homebrew tap for [SkillHub](https://github.com/Ant1Van/SkillHub) — The open-source desktop manager and marketplace for Claude Code skills.

## Installation

```bash
brew tap Ant1Van/tap
brew install --cask skillhub
```

Or as a single command:

```bash
brew install --cask Ant1Van/tap/skillhub
```

## Update

```bash
brew upgrade --cask skillhub
```
